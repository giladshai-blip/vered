# Vered Automations

Recommended recurring workflows:

## Morning brief
Review today's calendar, new important mail, deadlines, open tasks, and preparation needs.

## Important email watch
Check for new high-priority messages and notify only when action is required.

## Calendar conflict watch
Detect overlaps, insufficient travel time, or missing preparation buffers.

## Evening review
Summarize incomplete tasks, tomorrow's schedule, pending replies, and preparation needed.

Actual scheduling should be implemented through the platform automation system rather than GitHub Actions unless a later architecture explicitly requires otherwise.
