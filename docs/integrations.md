# Integrations

## Primary Google services
Vered is designed to work with authorized access to:
- Gmail
- Google Calendar
- Google Drive
- Google Docs
- Google Sheets
- Google Slides
- Google Contacts

## Additional sources
Additional approved plugins may be connected later.

## Integration rule
The repository documents how integrations should be used, but credentials and tokens must never be committed here.

## Runtime principle
Personal data should remain in the source service whenever possible. Retrieve only what is needed for the current task.
