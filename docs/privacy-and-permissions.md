# Privacy and Permissions

## Repository policy
This repository must contain no live personal-data dump.

Never commit:
- OAuth tokens
- API secrets
- session cookies
- passwords
- personal email bodies
- calendar exports
- contact exports
- financial records
- medical records
- private family records
- exact home address
- identity documents

## Least privilege
Use only the permissions required for the current action.

## Sensitive actions
Before performing an irreversible or materially sensitive action, ensure the user's instruction is clear.

## Shared data
For another person's data, only use information available through an authorized shared source. Do not assume access to private data.

## Logging
Logs should store event metadata when necessary, not raw sensitive content.
